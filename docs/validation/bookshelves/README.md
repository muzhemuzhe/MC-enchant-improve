# 0.4.2 书架验证

固定Minecraft26.1.2 / Fabric / JDK25；确切命令、结果和限制在 DEVLOG。日志按仓库公共规则只将开发机绝对路径改为相对路径。

## 覆盖

- 纯Java：80唯一候选、每层40、四方向几何相同、只数一次、混合已加载/未加载视图不读取缺失位置、0/1/15/16/32/35/36/37/60/80数量。
- 概率：最低等级全合法支持集严格为正；默认每架1..36的首选稀有概率与给定附魔最高级概率严格上升，后段边际因子递减；36/37/80抽取完全相同；旧scale=15自动接入后段，scale可到36。
- 真实服务端：四方向整机、上下两层、贴边/第二圈/角落、无空气通道也可计数、范围外不计、真实注册模组方块通过原版标签接入、动态报价与同上下文恢复、旧请求不付费、36架实际附魔精确匹配预览与费用。
- 未加载世界坐标：只创建坐标用block entity用于调用扫描适配器，不创建该位置的机器或区块。远处80候选均未加载，扫描后仍全部未加载、服务器loaded chunk数量不变。另有纯Java混合加载视图防护；这些测试不等同于玩家远离后的完整区块卸载压力测试。
- 真实OpenGL客户端：正常开口式两层书架结构、真实菜单/槽位/鼠标点击和网络同步，15/16/35/36动态变化、37实际架仍显示36/36且报价不变、分别拆上/下层、恢复36后相同结果，真实扣费后磁盘重进、拆机器不动外部书架。原结构、随机、指定四项客户端回归保留。

## 客户端布局

测试在机器的两个实际高度各放18架，总36。每层：x=±2且z=-1..1的贴边侧墙（6），z=2且x=-2..2的后墙（5），z=3且x=-3..3的第二后排（7）；前方开口，不影响打开机器。扫描范围内其他任意位置同样可用，**此布局只是测试夹具，不是玩法要求**。

世界截图从扫描范围外的临时玻璃观察台拍摄。书架和机器都是实际世界方块；不是界面模拟。菜单测试用真实鼠标、原版槽位和网络；Shift转移沿用已记录的官方TestInput修饰键补偿。未声称人工逐块建造或人工手动鼠标验收。

## 概率输出

`balance/actual-registry-simulation.md`：真实钻石剑8种合法附魔，固定seed20261016、选项三，T=1/3/5 × B=0/1/15/16/32/35/36/37/80；27×100,000次。每次检查适配/正常等级/互斥，报告统计首选稀有度、等级及多重数量。每个txt是所有结果的逐种类逐等级计数。

`balance-comparison.json`：原0/15六份txt与0.4.1逐文件一致，三个tier的36/37/80输出逐文件一致。证明严格正性与逐架概率改善用解析单元断言；有限模拟只作行为与统计检查，不替代数学保证。长期平衡未定。

本次不改碰撞体、模型、存储格式、种子机制、附魔合法池、指定30级门槛或GUI隐藏该门槛的设计。仍需真实整合包/资源包、非默认字体和高延迟多人验证。
