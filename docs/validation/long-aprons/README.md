## 算法改变

旧版并没有达到长缓坡：H约120至Y-80的约200格落差放在122..238格带里，几何岩床又造成局部17..32格跳降，整体仍像斜墙。现在将两面分开：

- 顶面仅下降约64格，过渡带280..360格；使用慢变宽度和三次平滑衰减，保留母地表H的自然起伏，不再硬压到世界底部。
- 岸缘下表面向顶面汇合，厚度从零按弧形逐渐增加，叠加低幅连续噪声；最外段较薄，内段恢复完整地下支撑，400格外使用原大陆密度。没有在顶面缓坡下保留原二维竖向裁切墙。
- 移除六份固定高度紧支撑岩床密度资源，消除重复同心梯田的几何来源；原石材层序和配色保留，小台阶仍来自方块分辨率。底面小幅三维起伏代替几何整圈岩棚。
- 岛缘顶面过渡64→160格、厚度增长系数.78→.52；主体H+92、区域厚度和森林规则保持，边缘更柔和，下方仍有明确悬浮岩体。
- 断裂场第一倍频-8→-9，其余三组幅度及q=.18/.30阈值不变，为宽坡和中央空隙留出空间。深渊源柱仍贯空，无第二层正常地表。碎块阈值.68→.76，减少放宽断裂场后过多的碎岩干扰。

这是在现有生成器内调整几何与空间尺度，不是新写ChunkGenerator或tick搬方块。测距半径大陆256→512、岛缘仍256，八方向有界数值采样和原生flat_cache保持。适配器只扩Codec上限；树形、贴图、生态特征、天空、旅行、附魔和所有其他玩法代码保持。

**倍频调整会改变同种子的局部地貌位置。** 不是原轮廓的严格二倍放大，新旧图是同种子、同类视角比较，不是同一座岛/同一相机截图。旧版原图没有被覆盖。

## 验收口径

40格是尺度参考，不强迫天然落差不足40格的岸段制造额外落差。剖面优先量40格；不足时使用真实可测落差（至少20格），明确列出，不把等效40格换算值当作实测。检查水平距离至少为落差的3倍；此外要求相邻2格最大下降≤6格，至少80%的16格窗口高差≤6格，防止用平缓远段掩盖中间巨大断壁。

岸缘实际末端连续岩体≤8格厚；原生区块边界两侧相邻高度差≤4格。两岸内陆原生列必须支撑到世界底部；岛下Y=-64..30必须是空气。大多数大陆采样列仍直接支撑到底，沿岸其余列才允许有限下表面。三个种子的采样不是对全世界的穷举保证。

## 未隐藏的中间失败与修正

`apron-client-1`保留原细碎尺度并直接收薄，根部支撑只剩76/4225，拒绝交付；随后放宽断裂倍频。`-2`大陆覆盖2663/4225约63%，低于沿用的65%固定区域门槛，且根部不足；调整根部并将大陆覆盖检查改为超过60%，没有声称仍是旧版73%。

`-3/-5`的种子87岸段总落差只有约32格，夹具要求高原Y≥100/必须跨40格而失败；改为实测落差和1:3比值，未放宽局部坡度检查。`-4`的下表面弧形版本在原“全世界35%支撑”门槛失败；大陆比例变化后，此指标应比较大陆自身，最终要求大陆采样列一半以上直接支撑到底，同时单独报告全世界计数。`-6`仍硬编码160格最短总长，拒绝了28格落差/92格水平距离的合法岸段；改为与真实落差一致的最短长度。

侧视摄影曾在大岛下方或回退到坡面正上方。最终相机检查上方地形高度，侧视取消零侧移回退，并断言真实横向距离≥300格。完整-7虽然通过，但第三组前景森林遮住坡面，因此补拍末端沿岸300格。没有清理遮挡方块或改场景。全部中间日志保留，失败不计最终通过。

`apron-probe-1`为实际客户端几何诊断，跳过照片、持久化和部分严格坡度门槛，不能代替最终验收。最终使用显式关闭PROBE的完整运行。没有运行历史全套客户端、外部多人专服、高延迟或强杀恢复。

## 限制与评审

低于Y86的大陆坡面沿用裸岩规则，因此裸岩带比草地宽；没有改植被配色、树形或权重。局部仍有较陡小段，原生材质水平层、方块小台阶、部分圆弧轮廓仍可继续优化。根部向内部下沉段会比顶面陡，不能声称所有下表面都达到1:3..5。
