## 轮廓怎样改变

旧算法在所有高度用同一个二维轮廓裁切大陆，岛厚又在窄带内快速封顶，导致百格垂壁。现在用有界噪声轮廓距离控制实际高度和厚度：

1. 大陆接近断口时，地表在不等宽带内逐渐下降，原断口线处已低于世界底部。远大陆仍实心支撑到世界底部，断裂核心依然贯空。
2. 随位置偏移的两组岩床直接参与三维密度，产生向外岩棚、向内凹陷与局部断崖；岩床强度沿边缘变化、渐隐，不重复固定宽度阶梯。撤去原来单独附在断壁外的残脊项。
3. 大岛上表面仅在64格外缘内渐降，底面厚度随向内距离平缓增加；共享母地层但使用不同幅度/三维侵蚀，保留不对称厚重岩体。内部山丘、森林、区域布局和统一92格抬升量不变。

仍采用原生 `minecraft:noise` ChunkGenerator、MultiNoise群系和数据密度图。仅新增 `differentenchant:fault_edge_distance` 标量函数，八方向、最多256格数值寻线，无世界/区块访问；线程缓存只有单个XZ，无tick工作。原生外层flat_cache与插值负责跨块连续，输入不带邻块敏感的缓存标记。没有搬运方块、人工造景或改写玩家存档。新岩层地形不会把深渊重新填平。
