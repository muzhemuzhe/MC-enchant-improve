## 采集与安全边界

新增9个服务器测试，加上原有48个（包含1个原版测试）；36个JUnit是既有纯逻辑回归。矿物测试使用真实服务器玩家和原生`gameMode.destroyBlock`提交，未直接调用掉落函数伪造采集结果。

- 五种保护类附魔书、摔落缓冲IV、主手火焰保护护甲、火矢书、火焰附加剑都实际破坏并得到一份正确资源。火焰保护同时通过两种矿石。
- 从正式失落标签迭代全部已注册项并逐一采晶簇，没有复制17项名单；普通保护、火矢、锋利、经验修补、灵魂疾行和迅捷潜行不能替代失落分类。
- 两类原生组件、已有兼容测试模组物品均通过。仅测试资源包给现有`probe`附魔追加火焰标签，验证可扩展性；正式JAR不含这个夹具，也没有新增附魔。
- 自定义名称/光效、空手、普通钻石镐/下界合金镐、仅穿戴保护护甲或副手持书均不能获得材料。精准/时运不能绕过，合格+时运也只给一份。
- 合格物品进度统一1/30每刻，材质无关；完成前换成无效主手不掉资源。最后一点耐久的合格工具损坏后，本次快照仍只发一份；创造移除无额外掉落。
- 通用loot上下文即使带玩家和合格工具也为空；实际玩家引发爆炸、实际通电活塞破坏晶簇、六方向支撑被移除均无特殊资源。矿石本身不可被活塞移动。
- 水含量状态及环境销毁无掉落通过。这里没有把一次水含量/环境测试冒称完整流水冲刷压力测试。所有资源由服务器玩家提交产生，客户端不发送自定义掉落指令。

客户端实际按住原生攻击键、等待服务器确认方块移除，并统计背包与附近实体总数；每次采集清理上一个夹具的材料，避免误把拾取的旧掉落当作新掉落。

## 自然生成、可重复性与存档

新世界种子`2026102001`，围绕区块(4,20)、(4,36)逐环巡查，18个区块找到浮辉石201、谐银矿80、裂空晶簇15，其中下向9、侧向6；每个晶簇真实支撑均有效。这是局部样本，不是全世界平均密度。独立第二个同种子世界按相同顺序再次生成，矿物位置/类型/朝向签名同为`-5910490027877474838`。

自然摄影目标分别为浮辉石(70,148,333)、谐银矿(78,147,311)、悬岛底面晶簇(74,147,329)、低处断面晶簇(66,51,588)。没有放矿、清空岩层、人工搭场景或增加照明方块。摄影用创造飞行，实际采集用生存加开发飞行以免从底面坠落，并授予原版夜视以看清暗岩面；这些都是测试角色设置，不是新玩法。

完整客户端关闭并保存世界、从磁盘重新打开后，保留晶簇/支撑状态与三种材料栈一致，返回主世界通过。物品栏图中的六种展示物品与三本书由测试夹具授予，不能把该库存展示当成全部采集所得。

旧0.18世界副本：已有区块(0,32)矿物数0，新生成区块(256,256)出现78个新矿物，旧区块仍为0；原岩石位置/类型指纹`-4117190361135751216`不变。第二次legacy测试扫描全高度真实母岩并断言岩石数量大于0，替代第一次只扫描低Y虚空的弱指纹。没有为旧区块补矿或删除区块。

两种群系仅增加矿物stage6、晶簇stage7；其余字段及植被stage9未改。生成特征有明确Realm维度守卫，实际对主世界调用三份配置均拒绝。矿脉复用原生三维OreFeature，晶簇只在自身区块内部合法岩面放置，无跨区块写入/票据/tick扫描。没有重做大陆、深渊、悬岛、边坡、树木或天空。

## 目前限制

- 当前是可运行的基础矿物版本，纹理/晶刃美术仍供审核；暗处不用夜视时辨识度更低，未为截图改变维度照明。晶簇实际自然样本验证了下向和侧向，六方向行为由服务器测试覆盖。
- 本轮完整客户端集中一个新种子、独立同种子重放及一个历史世界副本；未做大规模跨种子统计、长时多人服性能或独立远程网络压力测试。服务端GameTest用测试玩家，客户端实测用集成服务器。
- 同步巡查/摄影期间客户端记录4.139秒和5.546秒追赶，不能宣称没有世界生成开销。现有各向异性选项0报错/开发环境认证提示属于既有环境；没有新增缺失模型、贴图、注册表或生成错误。
- 资源用途、经验/数量平衡、时运增益等没有擅自设计；当前合格固定一份，旧区块不补矿。
