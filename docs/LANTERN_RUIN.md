# 大型灯笼遗迹原型 · 0.7.0

本轮新增一栋独立地上遗迹，不改已接受的小屋与中型，不实现大型宫殿、研究台或任何附魔玩法。

## 建筑与模板

- ID：`differentenchant:lantern_sanctum`；模板 `differentenchant:ruins/lantern_sanctum`。
- 尺寸33×33×26（宽×深×高，包含留位）；实际最宽玻璃层31格。局部原点(0,0,0)，地基Y0，北门/负Z，围绕原点原生四向旋转。
- 平面为切角八边形：中部满足 `|x−16|≤15`、`|z−16|≤15`、`|x−16|+|z−16|≤22`。模板不写八边形外的空气，因此不会整块矩形切空地形。顶部逐层收至半径10，底部收为石基；独立入口有两级浅台阶。
- 玻璃1048块，墙体玻璃/石英柱/木环梁统计中玻璃占62.9%。骨架为石英柱、平滑/錾制石英、去皮白桦木，地面白桦木，浅色屋冠苍白橡木台阶；石砖仅地基与有限地形支撑。全部原版材料，没有新贴图。
- 三层地板局部Y=1/8/15；上下廊围绕11×11挑空，两段折返楼梯联通。有护栏及书架、讲台、研究桌、蜡烛；不放刷怪笼。
- 一层红黄棋盘地毯，家具沿边布置，中心保持通行。二层四组雕纹书架沿用原生随机附魔书loot标记；与现有书架填充机制相同，不固定附魔列表。
- 顶冠有 sea lantern、ochre/pearlescent froglight、end rod，共305个发光方块（包含悬挂中央光棱与顶棚）。夜间截图无夜视；照明是实际方块光，不是模拟效果或着色器泛光。

建筑源是 `tools/lantern-ruin.mjs`，由 `tools/generate-ruins.mjs` 输出原生压缩NBT与清单。玩家及Gradle构建不依赖Node。`node tools/verify-lantern.mjs` 检查真实NBT、对称轮廓、未写矩形外空气、玻璃占比、发光量、桶候选/地毯覆盖、结构/loot引用及旧建筑锁。

## 隐藏木桶

候选坐标为 X∈{9,13,19,23}、Z∈{9,13,19,23}、Y=1，共16处；其上Y=2为棋盘地毯，模板中全是正常木地板，没有固定木桶或固定物品。

原生 `RuinStructure.findGenerationPoint` 仅在灯笼选址成功后从 `GenerationContext.random()` 取一次long，保存在Piece的 `CacheSeed`。旧结构不多消耗随机数，原生成流不变。`LanternCachePolicy` 使用该种子稳定抽取4–7个不重复位置，其余仍为木地板；具体子集和loot种子与区块处理顺序、旋转无关。纯Java Random仅是世界生成种子的确定性子流，不使用时间或客户端随机数。

每次原生Piece处理一个区块时，先正常放模板；只将选中且落在当前chunkBox内的地板替换为朝上的原版木桶，完整保留上方地毯。种子与局部X/Z混合，写入桶原生 `LootTableSeed`，`LootTable` 指向 `differentenchant:chests/lantern_cache`。内容在实际打开时由原版容器延迟生成。没有跨区块扫描/取块、运行时全局事件或玩家到访重新抽桶逻辑。

原型loot：3–5次书/纸/青金石/经验瓶/少量金锭/16–28强度随机附魔书；独立池1/12铭纹石、1/64零能量普通共鸣核心。不是每桶保证附魔书或稀有材料，不提供谐调核心或未实现研究物品。附魔书通过原生 `enchant_with_levels` 和 `#minecraft:in_enchanting_table` 生成。

玩家需要移开地毯找到桶。截图中的一处移毯只为演示：生产模板生成后仍全覆盖。桶/loot引用/种子与普通原版容器一样保存，不添加新库存协议。

## 自然生成与试放

复用现有 `differentenchant:ruin` StructureType/PieceType，通过新的Structure和StructureSet数据注册，不新增第二套生成框架。

- 主世界地表，旧 `#differentenchant:ruin_land` 标签：平原、向日葵平原、森林（含白桦森林）、针叶林、草甸。
- `random_spread` spacing48、separation24区块，salt1017344；避开村庄10区块。大于中型36/16、小型20/8的候选间隔，实际密度还受地形/生物群系过滤影响，不能把48解释为每48区块必有一栋。
- 沿用9点地形高度探测、海平面限制、最大坡差4格，选择最高采样高度为基准；仅模板实际石基单元向下最多支撑6格。没有强行加载区块、整块地形平整或大型人工平台。
- `/locate structure differentenchant:lantern_sanctum` 找自然实例。
- `/place structure differentenchant:lantern_sanctum` 走结构的正式选址/旋转/内容流程；仍受地形筛选，不保证任意陡坡可放。直接 `/place template` 只会放NBT，**不会调用Piece的随机藏桶与书架标记处理**，不能用于验证完整内容。

## 验证与后续

[专项测试、原始日志、截图](validation/lantern/README.md)。实际验证包含四向原生模板、正逆区块顺序、Piece和容器保存、自然主世界实例、磁盘重进、实际开门/步行/开桶及无夜视夜景。没有跑随机/指定附魔、UI、36书架或核心全套回归，相关生产代码未改。

仍为建筑/生成原型：建筑外观待试玩审核；48/24频率、4–7桶和奖励密度未最终平衡。仅一个普通种子自然实例，森林树木、陡坡、山沿和大范围多种子分布需要后续测试；入口地形接合可能需少量微调。当前只避让村庄，没有增加本模组不同遗迹之间的额外排斥。未做废弃破损变体、更多灯笼尺寸、谜题/新生物或长期掉落平衡。
