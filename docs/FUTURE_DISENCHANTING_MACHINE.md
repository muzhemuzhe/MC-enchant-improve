# 未来独立祛魔机（本轮只记录方向）

祛魔不属于当前 Differentenchant 附魔机。未来另行开发独立多方块结构、模型和 GUI，制造难度高于现有附魔机；本轮不实现，不添加祛魔标签页。

- 玩家选择装备上的一条附魔提取为附魔书。
- 原等级大于 I 时，提取书等级降低一级；I 级仍为 I。
- 被选附魔从装备移除，其他附魔及无关数据组件保留。
- 可研究普通砂轮无法处理的某些特殊附魔，但不能假定所有第三方特殊附魔都能安全提取。
- 诅咒、非标准附魔、其他模组的不可移除标记，需要独立兼容性与配置策略；未知规则默认谨慎拒绝，不能以清空组件绕过约束。
- 未来单独研究配方、结构尺寸、材料稀有度、特殊附魔准入及费用，并用真实模组验证。
- 三个新遗迹与原版要塞图书馆未来作为铭纹石主要来源，本轮也不生成这些内容。
