# 附魔者维度 · 自然断层坡与岛缘收束（0.17.0）

Enchanter’s Realm 保留有完整地下支撑的主体大陆，只在局部板块断裂区域挖出深渊，再把同源的大块地形抬升到上方。关系仍是“大陆 → 深渊 → 抬升大岛 → 深渊 → 大陆”。0.17.0 只改交界处几何：宽岩坡、实际进退的岩床和渐薄岛缘，保留冷色草地、青蓝森林与四种树形。

[本轮三种子真实客户端截图与验收](validation/fault-slopes/README.md)；[0.16.0 布局基线](validation/rift-plates/README.md)、[0.15.0 整体悬空方案](validation/skylands/README.md)、[0.14.0 初版](validation/realm/README.md) 均作为历史保留。当前方向不再是整个群系悬空。

## 开发入口与存档

管理员权限等级 2：`/differentenchant dimension enter`、`/differentenchant dimension return`。没有传送门、入口物品、生存条件或机器等级绑定。

`enter` 先以原生高度查询探测最多 25 个固定位置，范围至原点附近约 1544 格；查询不加载区块。优先选择 Y=86..169 的主体大陆，选定后只显式请求一个 FULL 目标区块，在该区块 16×16 范围检查支撑、两格空间、流体、世界边界、碰撞与危险方块。正常区块生成会准备原生依赖；没有持久票、强加载集合或后台扫描。找不到安全位置就失败，不搭平台、不清除地形。

来源维度、双精度坐标与视角按 UUID 保存到世界级 `data/differentenchant/realm_return.dat`。重复入境不覆盖锚点；成功传送才写入或删除。返回优先精确复原，原地受阻则在原区块内寻找安全地面；失败保留记录。无记录时仅尝试主世界原点附近一个区块。成功往返清理摔落距离并使用原生零速度传送。SavedData 沿用既有损坏保护，不能读取的旧数据不会静默覆盖。

**评审使用新测试世界。** 0.17.0 改了断岸和岛缘密度，不迁移或删除旧区块；继续旧版本存档会有新旧边界。自动化只在 `build/client-gametest/saves/` 新建世界，没有操作玩家原存档。

## 大陆、断裂与抬升的关系

使用 26.1.2 原生 `minecraft:noise`、`minecraft:multi_noise` 与密度函数 JSON。世界高度 -64..319，海平面 -64、默认流体空气，关闭含水层与矿脉。没有自定义 ChunkGenerator、真实搬运已生成方块、tick 扫描或手工修补。

1. **主体大陆**：母地表 H 由约 Y=118 的基准、较缓起伏、丘陵、山脊及浅谷组成，其参数与 0.16.0 相同。远离断口仍从世界底部实心延伸至 H；底部四层为基岩。大陆没有有限底面，不会把整个群系悬起来。
2. **局部深渊**：二维板块场 q 沿用 `uplift` 的原噪声参数。在 q>0.18 的局部区域移除原大陆整根竖向密度，包括抬升岛下方；没有第二层地表、水层或基岩底板。外侧大陆新增向断口下降的宽幅坡带，坡脚在旧轮廓前就沉到世界底部以下，因此不会在同一条轮廓上硬切出百格立墙。
3. **大块抬升**：同一片 q>0.30 内部核心仍由 H+92 形成大岛。顶面只在外缘 64 格带内渐降最多26格；厚度从零随向内轮廓距离增长，约为 0.78×距离，再受 `62+14×underside` 的区域深度限制。岛内上表面不改。核心与挖空边界之间仍有 q=0.18..0.30 的深渊间隔，岛下源柱同样空出。岛屿尺度由连续区域场控制，不是按区块撒小岛。
4. **同源断口**：外裂口和岛缘是同一噪声场的两个等值轮廓，局部凸凹趋势呼应；岛面保留原 H 的丘陵走向。地表与岩层也以母地层定义，岛上使用 y-92 的地层坐标，深浅岩层一起抬升。不是独立随机岛叠在无关山地上。
5. **残留连接痕迹**：原有 q≈0.18..0.36、Y=36..166 的高阈值碎岩保留；撤去独立贴在断壁外的旧残脊密度。中尺度岩棚现由岩床直接改变主体几何，不铺新底板，不保证每处都有可通行石桥。

这里描述的是生成密度的组合，不会真的加载旧区域再搬石头。原生跨区块采样和插值负责边界，种子驱动重放。主体大陆和岛面都采用原有土壤、树木与草花特征，陡峭断面露出深浅岩；没有新增建筑、战利品或生物。

## 边缘距离、宽坡与真实岩棚

0.16.0 的 `min(二维mask,竖向密度)` 在所有高度用同一条 XZ 线裁切；`2800×lift_mask` 又让岛厚在极窄范围内封顶。水平材质条纹无法改变这个竖墙轮廓。0.17.0 从密度层解决：

- **距离**：`fault_edge_distance` 对种子绑定的同一原生噪声，在八个方向进行最多256格的有界寻线，16格起步、24格步进、五次二分细化。梯度只决定先查哪个方向，不参与除法，避免鞍点附近距离爆跳。输入为无 chunk 缓存标记的原始噪声图；外层 `flat_cache` 使用原生四格 XZ 网格，适配器另有每线程单个 XZ 的常量内存缓存。`mapAll` 明确遍历输入并重建适配器，保证每世界正确绑定噪声和隔离缓存。它只查询数值，不加载邻块、不访问方块。
- **大陆大坡**：令内侧距离为 d，噪声调节坡率 r（.0042.. .0082，完整归一化坡带约122..238格），t=clamp(1-d×r,0,1)。基准面为 `H-(H+80)×(.6t+.4t²)`；旧轮廓 d=0 时已低至Y=-80。实际地表随 H、r 和岩床变化，既不是固定45度，也不是沿墙贴随机石头。
- **中尺度岩床**：两个岩床中心高度随连续噪声偏移，分别围绕Y74±20、Y40±22；纵向紧支撑范围15/21格。沿边缘缓变的正负振幅让不同层凸出、回缩、渐隐，名义横向位移可达约29格；再加小幅三维破碎。它们直接扰动距离/表面密度；地表高差额外限幅±14格，避免陡坡放大成另一道巨大断墙。不按固定高度重复同宽台阶。
- **岛体**：底部用相同母地层坐标 y-92 呼应大陆，但采用不同三维噪声、0.60强度，外缘48格内逐渐退去扰动，厚度从零平缓增长。底面因区域厚度、纵向岩床及三维侵蚀而不规则；不使用一个统一圆锥或平底。表面保持原生土壤规则，树木仅在合法上表面、全树预检通过后生成。

三种子实际原生剖面中，大陆从约Y90降到Y0的水平宽度为58/86/66格；岛缘厚度从5增至30格用32/32/26格。14处剖面区块边界相邻高度差最大2格。它们是所选剖面的实测，不是所有边缘的全局保证；局部仍有最高32格的小断崖。更多数据见[验收](validation/fault-slopes/README.md)。

原野/青林仍使用连续湿度采样，以树木疏密过渡。浅谷当前是干切口，没有悬空水道、瀑布或湖泊系统；草地仍为临时固定色纹理。统一92格抬升保持。局部岩坡仍宽而圆滑、有碗状凹弧，紧凑岛仍可能偏椭圆；未来可针对区域美术反馈微调，不重换布局。20区块摄影同步巡查产生约9–17秒追赶警告，尚不能视为长时多人性能验收。

## 青木四种轮廓

| 形态 | 尝试比例 | 形状 |
| --- | --- | --- |
| SPIRE 高瘦 | 36% | 约 7–10 格主干加顶梢，三层竖向椭球叶团与短枝 |
| WINDSWEPT 风塑 | 32% | 主干倾移 2–3 格，向风方向上扬分枝、偏移树冠 |
| FORKED 分叉 | 27% | 低位分叉后形成三条上升木枝，不对称多团树冠 |
| ANCIENT 粗干 | 5% | 2×2 基部、约 9–11 格主干、五条上升枝、大团叶冠与短板根 |

比例是形状尝试权重，不是最终森林占比；粗干树需要四格平整土壤和较大空隙，因此实际更稀少。这是0.15.0沿用的低频视觉锚点，不是未来专属巨型古树；本轮未改树形或权重。

叶团是有竖向体积的三维椭球，边缘较疏、内部留少量缺口，偶有短垂叶。木质均六面连通；叶距通过真实叶块路径 BFS 计算为 1..6，无路径叶片直接剔除。全树预检遇到固体、流体、既有叶冠或超出 WorldGenRegion 写入窗口就整棵拒绝，不破坏山体、不强加载相邻区块。最大水平半径 11 格、叶片最高不超过基部 21 格。400 个固定形态样本测试连通性、真实叶路、尺寸和复现性，另以 2000 个混合种子检查分布。

旧版扁平双层圆盘冠已移除。现在仍有方块台阶状弯干、部分树冠偏密、同种树形近看相似的情况；后续可调枝条姿态与叶团分离度。没有树苗、木板或木材经济扩展。

## 天空、资源与范围

固定青蓝天顶 `#88c9e0`、淡紫远雾 `#c9c7e7`、Y=272 原生云层、15 级天空光和 0.16 环境光。按 26.1.2 源码使用 `has_fixed_time`、空 `timelines`、不绑定 `default_clock`。`RealmSkyMixin` 仅按本维度 ID 跳过日月星体，并启用原生下半天空暗盘。下方因此呈深色虚空，远景明暗交界目前比较平直，还没有定制深空渐变。没有新着色器、全屏效果或粒子压力；其他维度不走此条件。

八张 16px 纹理均是可重建的 Minecraft 临时调色资源：石头、凝灰岩、泥土、草方块、云杉原木及橡树叶。不是最终原创美术；来源见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)。没有新增建筑、怪物、动物、矿物、Boss、战利品、附魔机制、隐藏进度或机器升级。

测试命令和每张真实截图的种子/相机坐标见[本轮验收](validation/fault-slopes/README.md)。15张截图全部使用创造飞行以展示完整轮廓，等待实际下载区块和网格渲染后摄影；只调整玩家位置/视角、隐藏界面，树木与地形全部来自正常生成。
