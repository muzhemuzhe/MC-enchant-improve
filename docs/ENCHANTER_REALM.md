# 附魔者维度 · 大陆断裂与抬升地块（0.16.0）

Enchanter’s Realm 的主体恢复为有完整地下支撑的连续大陆，只在局部板块断裂区域挖出深渊，再把同源的大块地形抬升到上方。目标关系是“大陆 → 深渊 → 抬升大岛 → 深渊 → 大陆”。保留冷色草地、青蓝森林与上一轮四种树形。

[本轮真实客户端截图与验收](validation/rift-plates/README.md)；[0.15.0 整体悬空方案](validation/skylands/README.md)、[0.14.0 初版](validation/realm/README.md) 均作为历史保留。当前方向不再是整个群系悬空。

## 开发入口与存档

管理员权限等级 2：`/differentenchant dimension enter`、`/differentenchant dimension return`。没有传送门、入口物品、生存条件或机器等级绑定。

`enter` 先以原生高度查询探测最多 25 个固定位置，范围至原点附近约 1544 格；查询不加载区块。优先选择 Y=86..169 的主体大陆，选定后只显式请求一个 FULL 目标区块，在该区块 16×16 范围检查支撑、两格空间、流体、世界边界、碰撞与危险方块。正常区块生成会准备原生依赖；没有持久票、强加载集合或后台扫描。找不到安全位置就失败，不搭平台、不清除地形。

来源维度、双精度坐标与视角按 UUID 保存到世界级 `data/differentenchant/realm_return.dat`。重复入境不覆盖锚点；成功传送才写入或删除。返回优先精确复原，原地受阻则在原区块内寻找安全地面；失败保留记录。无记录时仅尝试主世界原点附近一个区块。成功往返清理摔落距离并使用原生零速度传送。SavedData 沿用既有损坏保护，不能读取的旧数据不会静默覆盖。

**评审使用新测试世界。** 0.16.0 改了大陆支撑与局部断裂密度，不迁移或删除旧区块；继续旧版本存档会有新旧边界。自动化只在 `build/client-gametest/saves/` 新建世界，没有操作玩家原存档。

## 大陆、断裂与抬升的关系

使用 26.1.2 原生 `minecraft:noise`、`minecraft:multi_noise` 与密度函数 JSON。世界高度 -64..319，海平面 -64、默认流体空气，关闭含水层与矿脉。没有自定义 ChunkGenerator、真实搬运已生成方块、tick 扫描或手工修补。

1. **主体大陆**：母地表 H 由约 Y=118 的基准、较缓起伏、丘陵、山脊及浅谷组成。普通位置从世界底部连续实心延伸至 H；底部四层为基岩。这里没有有限底面，因此不会再把整个群系悬起来。
2. **局部深渊**：独立的连续二维板块场 q 使用 `uplift` 噪声。在 q>0.18 的局部区域移除原大陆整根竖向密度，包括抬升岛下方；深渊里没有第二层地表、水层或基岩底板。外侧大陆保持地下支撑。阈值边缘由原生四格密度插值平滑衔接。
3. **大块抬升**：在同一片 q>0.30 的内部核心，把同一母地表 H 上移 92 格生成岛面，岛底由 0..62 格可变厚度、弱岩床和三维侵蚀决定。核心与挖空边界之间有 q=0.18..0.30 的深渊间隔，岛下源柱同样空出。岛屿尺度由连续区域场控制，不是按区块撒小岛。
4. **同源断口**：外裂口和岛缘是同一噪声场的两个等值轮廓，局部凸凹趋势呼应；岛面保留原 H 的丘陵走向。地表与岩层也以母地层定义，岛上使用 y-92 的地层坐标，深浅岩层一起抬升。不是独立随机岛叠在无关山地上。
5. **残留连接痕迹**：在 q≈0.165..0.235 的断岸附近，用高频噪声保留有限岩脊/台阶；在 q≈0.18..0.36、Y=36..166 内生成高阈值碎岩链。残脊只在原地表下约 8..28 格出现，不能重新铺成深渊底板。本轮没有保证每处必有完整可通行石桥。

这里描述的是生成密度的组合，不会真的加载旧区域再搬石头。原生跨区块采样和插值负责边界，种子驱动重放。主体大陆和岛面都采用原有土壤、树木与草花特征，陡峭断面露出深浅岩；没有新增建筑、战利品或生物。

原野/青林仍使用连续湿度采样，以树木疏密过渡。浅谷当前是干切口，没有悬空水道、瀑布或湖泊系统；草地仍为临时固定色纹理。当前抬升量统一为92格，部分断口较直、岛底仍有圆滑地段；后续可按区域变化抬升量、增加斜断层与有方向的桥残段。

## 青木四种轮廓

| 形态 | 尝试比例 | 形状 |
| --- | --- | --- |
| SPIRE 高瘦 | 36% | 约 7–10 格主干加顶梢，三层竖向椭球叶团与短枝 |
| WINDSWEPT 风塑 | 32% | 主干倾移 2–3 格，向风方向上扬分枝、偏移树冠 |
| FORKED 分叉 | 27% | 低位分叉后形成三条上升木枝，不对称多团树冠 |
| ANCIENT 粗干 | 5% | 2×2 基部、约 9–11 格主干、五条上升枝、大团叶冠与短板根 |

比例是形状尝试权重，不是最终森林占比；粗干树需要四格平整土壤和较大空隙，因此实际更稀少。这是本轮低频视觉锚点，不是未来专属巨型古树。

叶团是有竖向体积的三维椭球，边缘较疏、内部留少量缺口，偶有短垂叶。木质均六面连通；叶距通过真实叶块路径 BFS 计算为 1..6，无路径叶片直接剔除。全树预检遇到固体、流体、既有叶冠或超出 WorldGenRegion 写入窗口就整棵拒绝，不破坏山体、不强加载相邻区块。最大水平半径 11 格、叶片最高不超过基部 21 格。400 个固定形态样本测试连通性、真实叶路、尺寸和复现性，另以 2000 个混合种子检查分布。

旧版扁平双层圆盘冠已移除。现在仍有方块台阶状弯干、部分树冠偏密、同种树形近看相似的情况；后续可调枝条姿态与叶团分离度。没有树苗、木板或木材经济扩展。

## 天空、资源与范围

固定青蓝天顶 `#88c9e0`、淡紫远雾 `#c9c7e7`、Y=272 原生云层、15 级天空光和 0.16 环境光。按 26.1.2 源码使用 `has_fixed_time`、空 `timelines`、不绑定 `default_clock`。`RealmSkyMixin` 仅按本维度 ID 跳过日月星体，并启用原生下半天空暗盘。下方因此呈深色虚空，远景明暗交界目前比较平直，还没有定制深空渐变。没有新着色器、全屏效果或粒子压力；其他维度不走此条件。

八张 16px 纹理均是可重建的 Minecraft 临时调色资源：石头、凝灰岩、泥土、草方块、云杉原木及橡树叶。不是最终原创美术；来源见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)。没有新增建筑、怪物、动物、矿物、Boss、战利品、附魔机制、隐藏进度或机器升级。

测试命令和每张真实截图的种子/相机坐标见[本轮验收](validation/rift-plates/README.md)。摄影只传送管理员、调整视角、创造飞行和隐藏界面，树木与地形全部来自正常生成。
