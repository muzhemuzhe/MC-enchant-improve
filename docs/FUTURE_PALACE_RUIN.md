# 大型宫殿遗迹 · 后续方向，尚未实现

这是第三种大型遗迹的风格备忘，不是本轮功能或最终规格。当前没有对应模板、Structure/StructureSet、战利品或生成注册。

- 目标约100×80×80（宽×深×高），可更大；重点是真正宏伟的宫殿群，不是把当前工坊按比例放大。
- 主殿、侧殿、塔楼、前庭与庭院组成可辨认的整体。高低错落的尖塔、长廊和屋顶构成远处剪影，避免单一长方体、石制据点或dungeon。
- 气质为华丽、苍白、优雅、神秘的附魔文明；本轮浅色木构、玻璃、藏书和克制紫水晶装饰作为风格参照，宫殿的最终材料配比另行研究。
- 室内应有藏书、研究、生活与管理空间，外形与内部动线一起设计，不能只有大壳或无意义的空厅。
- 下一阶段再评估分段结构模板、地形适配、跨区块放置、探索节奏和奖励；本轮不为它增加生成逻辑、研究台、Boss、维度或升级机制。
